1. ポータルでできること

内定者は、LINE などで受け取った専用の URL とパスワードでポータルを開きます。スマートフォンでの閲覧を前提にした画面です。

  • 今やること：提出物や準備するものを、期限の近い順に表示します。内定者は「確認した」「対応した」のボタンで状況を知らせます。
  • これからの予定：顔合わせやイベントの日時・場所です。インターンの出勤予定などは、内定者が自分で追加することもできます。
  • お知らせ：追加の案内です。大事なものを1件、一番上に固定できます。
  • 会社を知る：公式サイトや SNS へのリンク、職場の写真、動画やインタビュー記事を載せられます。

内定者ごとに専用のページになっていて、他の内定者の情報は見えません。

2. 運用の流れ

案内はまずポータルに載せ、LINE では「ポータルを更新しました」と伝えるだけにします。内容はすべてポータルに残るので、LINE のメッセージが流れてしまっても困りません。

1. 入力スプレッドシートに行を追加する
2. 公開「公開」にチェックを入れる
3. 連絡LINE で「ポータルを更新しました」と送る
4. 確認「進捗一覧」で、誰が対応したかを見る

スプレッドシートを変更すると、ポータルに自動で反映されます。保存ボタンを押したり、何かを公開する操作をしたりする必要はありません。

3. シートの一覧

スプレッドシートの下部に、シートのタブが並んでいます。青いタブはご担当者さまが編集するシート、グレーのタブは自動で書き込まれるシートです。

シート内容編集

表示文言挨拶や見出しの言葉必要なときだけ
内定者内定者の名前と状態。URL・パスワードの発行もここから内定者が増えたとき
予定顔合わせ、イベント、内定式など随時
やること提出物、準備するもの、回答してほしいもの随時
お知らせ追加の案内、固定のお知らせ随時
リンク会社HP、採用サイト、SNSはじめに1回
ギャラリー職場の写真はじめに1回
コンテンツ動画、インタビュー記事随時
記録_チェック／記録_自分の予定／ログ内定者の操作の記録（自動）編集しない

4. 共通のルール

予定・やること・お知らせ・コンテンツの4つのシートには、共通の列があります。

列使い方
ID・登録日時行に入力すると自動で入ります。編集しないでください。
公開チェックを入れたものだけがポータルに表示されます。書きかけのうちは外しておけば、内定者には見えません。
公開開始日日付を入れると、その日になるまで表示されません。空欄ならすぐに表示されます。
対象誰に見せるかを決めます（下の表）。空欄は「全員」と同じです。

「対象」の書き方

書き方表示される人
全員（または空欄）すべての内定者
承諾済／未承諾「内定者」シートの「状態」が一致する人
インターン中 など「内定者」シートの「グループ」が一致する人
S001,S003指定した内定者IDの人だけ（カンマで区切って複数指定できます）

リンク・添付の書き方

「リンク」「リンク・添付」の列には、表示名|URL の形で書きます。| は半角の縦線です。セルの中で改行すると、複数付けられます。

出欠フォーム|https://forms.gle/xxxxx
入社承諾書（PDF）|https://drive.google.com/file/d/xxxxx/view

Google ドライブのファイルや PDF、表示名に「PDF」「資料」「添付」を含むものは、添付のアイコンで表示されます。セル内の改行は、Mac なら ⌘ + Enter、Windows なら Alt + Enter です。

注意不要になった行は、削除せずに「公開」のチェックを外してください。内定者の「確認した」などの記録が ID に紐づいているためです。

5. 内定者を登録して URL を送る

  1. 「内定者」シートの空いている行に、氏名・表示名・状態を入力します。表示名は、ポータルで「〇〇さん」と呼びかけるときの名前です。グループは必要なときだけ入れます。
  2. 登録した人の行を選択します。複数の行をまとめて選んでもかまいません。
  3. 画面上部のメニュー「内定者ポータル」→「URL・パスワードを発行（選択した内定者）」を押します。
  4. 案内文が表示されるので、「コピー」を押して LINE などで本人に送ります。
注意パスワードは、この画面でしか確認できません。閉じる前に必ず送ってください。わからなくなった場合は、同じ手順で再発行できます。再発行すると、前のパスワードは使えなくなります。

状態が変わったとき

  • 内定を承諾した：「状態」を「承諾済」に変えます。対象が「承諾済」の案内が、その人にも表示されるようになります。
  • 内定を辞退した：「状態」を「辞退」にし、「利用」のチェックを外します。すぐにポータルを開けなくなります。

案内文の文面は、「表示文言」シートの「発行メッセージ」で変えられます。{名前}、{URL}、{パスワード} の部分は、自動で置き換わります。

6. やることを追加する

内定者に、提出や回答などの対応をしてほしいものです。

列書くこと例
タイトル何をしてほしいか入社承諾書の提出
説明やり方や注意点（改行できます）署名のうえ、郵送してください。
期限日付。空欄なら「期限なし」2026/10/31
リンク・添付フォームや書類入社承諾書（PDF）|https://…
完了の条件下の2つから選びます対応したで完了
  • 対応したで完了：内定者は「確認した」→「対応した」の2段階で押します。提出物や回答に使います。
  • 確認したで完了：「確認した」を押すだけで完了します。資料を読んでほしいときなどに使います。

期限の7日前からは、内定者の画面でオレンジ色の「あと◯日」と表示されます。完了したものは、「完了したこと」の一覧に移ります。

日付が過ぎた予定は、ポータルから自動で消えます。内定者が自分で追加した予定（インターンの出勤など）は、「記録_自分の予定」シートで確認できます。

8. お知らせを追加する

列書くこと
掲載日新しい日付のものから順に並びます
タイトル・本文本文は長くてもかまいません。空行を入れると段落が分かれます。一覧では冒頭だけが表示され、「詳細を見る」で全文が開きます。
リンク・添付詳細ページの下に表示されます
固定チェックを入れたものが一番上に固定されます。固定できるのは1件だけで、複数にチェックがある場合は掲載日の新しいものが固定されます。

固定のお知らせの下には、新しいものから3件を表示します。それより古いものは「過去のお知らせ」にまとめて表示されます。表示件数は「設定」シートで変えられます。

9. 会社紹介（リンク・写真・動画）

リンク

「リンク」シートの、使うものの URL 列に入力します。URL が空欄のものは表示されません。

写真（ギャラリー・トップ写真）

  1. Google ドライブに画像用のフォルダを作り、フォルダを右クリック →「共有」→ 一般的なアクセスを「リンクを知っている全員」にします。
  2. そのフォルダに写真を入れ、写真を右クリック →「共有」→「リンクをコピー」します。
  3. 「ギャラリー」シートの「画像」列に貼り、キャプションを書いて「公開」にチェックを入れます。トップ写真は、「設定」シートの「トップ写真」に貼ります。

ギャラリーは3〜5枚がおすすめです（最大10枚）。横長の写真がきれいに表示されます。

注意共有設定をしていない写真は表示されません。また、リンクを知っている人は誰でも見られる状態になるので、社外秘の写真は使わないでください。

動画・インタビュー記事（コンテンツ）

種類書き方
動画YouTube に「限定公開」でアップロードし、その URL を「URL」列に貼ります。サムネイルは自動で表示されます。
記事「本文」列に記事を書きます。お知らせと同じく、空行で段落が分かれます。
外部リンク見てほしいページの URL を「URL」列に貼ります。

「補足」には「3分」「2024年入社」などの短い情報を書きます。

11. 対応状況を確認する

「進捗一覧」シートに、内定者 × やることの表が自動で作られます。内定者がボタンを押すたびに更新されます。

表示意味
未確認まだ見ていない、またはボタンを押していない
確認済内容は確認したが、対応はまだ
対応済完了
対象外その人には表示していない
太字期限を過ぎているのに完了していない

「前回ログイン」が「未ログイン」の人は、まだ一度もポータルを開いていません。やることを追加・変更した直後に表を最新にしたいときは、メニュー「内定者ポータル」→「進捗一覧を更新」を押してください。

12. 困ったときは

こんなとき確認すること
追加した内容がポータルに出ない「公開」にチェックが入っているか。「公開開始日」が未来の日付になっていないか。「対象」がその人に合っているか。
写真が表示されないドライブの共有設定が「リンクを知っている全員」になっているか。
内定者がパスワードを忘れた「内定者」シートでその人の行を選び、「URL・パスワードを発行」で再発行して送り直します。
「ロックしています」と表示されたパスワードを5回続けて間違えると、15分間ログインできなくなります。時間をおいてから試してもらってください。
内定者がスマホを変えた同じ URL とパスワードで開けます。パスワードがわからなければ再発行してください。
ID がずれた・消えた自動の列なので、手で直さずに運営担当までご連絡ください。
その他、わからないこと運営担当までお気軽にご連絡ください。
内定者の住所・電話番号・学校名などの個人情報は、ポータルに載せないでください。
