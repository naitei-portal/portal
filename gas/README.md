# 内定者ポータル スプレッドシートの作り方

## ひな形（最初に1回だけ）

ポータル用アカウントで、すべての会社のもとになるスプレッドシートを1つ作っておく。

1. 新しいスプレッドシートを作る（名前：`【ひな形】内定者ポータル`）
2. 「拡張機能」→「Apps Script」→ 左の歯車「プロジェクトの設定」→ タイムゾーンを「日本標準時 - 東京」にする
3. 「＋」→「スクリプト」で次の5つを作り、このフォルダの中身を貼る（最初の `コード.gs` は削除）
   - `Config` / `Common` / `Setup` / `Admin` / `Api`
4. 保存 → スプレッドシートを再読み込み → メニュー「内定者ポータル」→「初期セットアップ」
5. 初回は権限の確認が出るので許可する（「詳細」→「安全ではないページに移動」→「許可」）

ひな形はデプロイしない。内定者の登録や URL の発行もしない。

## 新しい会社を追加するとき

1. ひな形を開き、「ファイル」→「コピーを作成」（名前の例：`【株式会社〇〇】内定者ポータル 2027`）
2. コピーを開き、「拡張機能」→「Apps Script」→「デプロイ」→「新しいデプロイ」
   - 種類：ウェブアプリ／実行ユーザー：自分／アクセス：全員
   - 権限の確認が出たら許可する
3. 表示されたウェブアプリの URL を運営担当（Claude）に渡す
   - 会社コード（ランダムな文字列）を作り、`docs/clients.js` に登録して公開する
4. 「設定」シートの「会社コード」に、受け取った会社コードを入れる
5. 「設定」の会社名・色・写真などを入れ、サンプルデータを消して実データを入れる
6. 「内定者」シートに内定者を入れ、「URL・パスワードを発行」→ LINE で送る

## コードを更新したとき

各社のスプレッドシートはそれぞれ別のコードを持つので、更新は会社ごとに行う。

1. そのスプレッドシートの Apps Script で、変更のあったファイルを貼り直して保存
2. `Api.gs` を変えた場合は「デプロイ」→「デプロイを管理」→ 鉛筆 →「新バージョン」→「デプロイ」
   - 「新しいデプロイ」にすると URL が変わるので使わない
3. ひな形にも同じ変更を反映しておく

## メモ

- 「内定者」シートの右側（アクセスキー以降）は非表示列。GAS が管理するので編集しない。
- 「記録_」で始まるシート・「進捗一覧」・「ログ」は自動で書き込まれる。
- 不要になった行は削除せず、「公開」を OFF にする（記録が ID に紐づいているため）。
