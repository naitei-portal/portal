# 内定者ポータル テンプレートの作り方

## 1. スプレッドシートを作る

1. Googleドライブで新しいスプレッドシートを作る（名前の例：`【株式会社サンプル】内定者ポータル 2027`）
2. メニューの「拡張機能」→「Apps Script」を開く
3. 最初からある `コード.gs` を削除し、このフォルダの4つのファイルを同じ名前で作って中身を貼り付ける
   - `Config.gs` / `Common.gs` / `Setup.gs` / `Admin.gs`
4. 保存し、上部の関数選択で `setupTemplate` を選んで「実行」
5. 初回は権限の確認が出るので許可する（「詳細」→「安全ではないページに移動」→「許可」）
6. スプレッドシートに戻って再読み込みすると、メニューに「内定者ポータル」が出る

## 2. 試してみる

- 「やること」や「お知らせ」に行を追加すると、ID と登録日時が自動で入る
- 「内定者」シートで行を選び、メニューの「URL・パスワードを発行」→ LINE用の案内文が表示される
- 「進捗一覧を更新」→ 内定者×やることの表ができる（画面と GAS の API ができるまでは全員「未確認」）

## メモ

- 「内定者」シートの右側（アクセスキー以降）は非表示列です。GAS が管理するので編集しないでください。
- 「記録_」で始まるシート・「進捗一覧」・「ログ」は自動で書き込まれます。編集しようとすると警告が出ます。
- 不要になった行は削除せず、「公開」を OFF にしてください（記録が ID に紐づいているため）。
